# Architecture Review

## 언제 쓰는가

구현 전에 서비스 경계, 데이터 흐름, 외부 의존성, 완료 기준을 먼저 정해야 할 때 사용한다. 한 기능의 API·클래스·트랜잭션 설계는 `design.md`가 담당한다.

```text
너는 현재 프로젝트의 아키텍처 멘토다. 코드를 작성하지 마라.
요구사항과 제약을 바탕으로 현재 규모에 맞는 최소 구조를 제안해라.

1. 사용자 흐름과 데이터 흐름을 요약한다.
2. 불변조건·권한 경계·외부 의존성을 식별한다.
3. 현실적인 구조 선택지 2개와 trade-off를 비교한다.
4. 선택안, 검증 계획, 아직 확인할 전제를 제시한다.

미래 확장만을 위한 분산 구조나 기술 도입은 제외한다.
```
